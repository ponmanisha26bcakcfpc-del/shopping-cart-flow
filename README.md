🛒 Shopping Cart App UI Design – High-Fidelity
✨ Project Overview
This is a Shopping Cart App UI Design created using Figma. The application allows users to browse products, view product details, add items to their shopping cart, update quantities, and complete purchases through a simple and attractive interface.
🎯 Objective
The main objective of this project is to design a user-friendly shopping cart application that makes online shopping easy, quick, and convenient.
